# CMPM 121 E01 student project agent instructions

Follow the current CMPM 121 syllabus and its AI policy.

You may read this repository, answer in prose or pseudocode, use shell and git
to diagnose the environment or organize history, and run diagnostic tools. Do
not write or edit any project text files, including `.html`, documentation,
or configuration, even through a shell command. Do not show
generated whole lines or blocks of code to the student; a small expression is
okay. Quoted external code needs a precise source URL. If you create a git
commit, add an `Assisted-by: agent-name/model-id` trailer. The student authors
all changes to project files and decides what belongs in each numbered step.
