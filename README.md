# Three small browser sketches

This repository contains three independent interactive pages:

- `a-lighting-controls.html`: installation lighting controls.
- `b-auto-targeting.html`: a game's auto-targeting display.
- `c-puzzle-renderer.html`: a puzzle renderer with two tile arrangements.

Open this folder in VS Code. With the Live Server extension installed, click
**Go Live**. From the browser's directory listing, open one of the HTML files
(or add its filename to the local address). There are no build
dependencies or separate JavaScript files. Each page keeps its JavaScript
inside the HTML file.

The work brief, checks, and submission instructions are in the CMPM 121 E01
Canvas exercise, not in this repository.
